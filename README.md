# Limak · Fuar Deneyimi

İki ekranlı interaktif fuar sunumu.

- **World with Limak** — çorak araziye sekiz sektörün yatırımlarını yerleştirdikçe
  dünya merkezden dışa doğru canlanır.
- **50 Yıl, Bir Miras** — 1976'dan 2026'ya 24 dönüm noktası.

Kaynak: Limak Şirketler Grubu 2025 Faaliyet Raporu.

Dokunmatik ekran ve klavye ile kullanılabilir. Sunucu gerektirmez.
